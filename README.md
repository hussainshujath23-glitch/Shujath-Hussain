# My Calendar

An importable iCalendar (`.ics`) file with fixed-date holidays for late 2026 and early 2027.

## Use it

Download `calendar.ics` and import it into Google Calendar, Apple Calendar or Outlook.

## Add events

Copy a `BEGIN:VEVENT ... END:VEVENT` block in `calendar.ics`, give it a unique `UID`, and change the dates and `SUMMARY`.
